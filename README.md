# Таймер стойки для Amazfit Bip 6

На часах с английским языком приложение называется **Saiga Stance Timer**. Интерфейс доступен на русском и английском и выбирается по языку часов.

По умолчанию раунд длится **3 минуты**. В режиме «30 и 60 с» часы подают один импульс на `0:30`, `1:30` и `2:30` после старта, два импульса с паузой на `1:00` и `2:00`, а на `3:00` дают длинный сигнал окончания. Для промежуточных сигналов задан импульс 150 мс и пауза 220 мс в двойном сигнале. [Вибрационные сценарии Zepp OS](https://docs.zepp.com/docs/reference/device-app-api/newAPI/sensor/Vibrator/)

- Нажимайте `−` и `+`, чтобы менять длительность от 1 до 99 минут. Долгое нажатие меняет её на 5 минут.
- Средняя кнопка переключает режимы «30 и 60 с», «Каждые 30 с» и «Каждые 60 с». Длительность и режим сохраняются на часах.
- «Проверить вибрацию» воспроизводит все три сигнала подряд и подписывает каждый на экране. «Стоп» завершает текущий отсчёт. По окончании «Повторить» запускает такой же раунд.

Нажмите «Старт»: сначала идёт **обратный отсчёт 5 секунд** («ГОТОВЬСЬ» и цифры 5…1), в последние три секунды часы коротко вибрируют, а в момент начала раунда дают один длинный импульс. «Стоп» во время отсчёта отменяет раунд. Если закрыть приложение посреди отсчёта и открыть снова, он продолжится, а раунд начнётся вовремя. Все сигналы раунда отсчитываются от его начала, то есть от конца отсчёта, а не от нажатия. Длину отсчёта задаёт `countdownSeconds` в `lib/round.js`; число импульсов в конце задаёт `countdownPulses` там же. Затем дайте экрану погаснуть. Часы запланируют промежуточные сигналы и финиш через системный планировщик. Чтобы посмотреть остаток времени или остановить раунд, откройте «Таймер стойки» снова. После установки телефон для отсчёта не нужен.

Для каждого сигнала системный планировщик будит короткую службу Zepp OS. Для её запуска не требуется динамическое разрешение на постоянную работу в фоне. [Планирование события Zepp OS](https://docs.zepp.com/docs/reference/device-app-api/newAPI/alarm/set/) · [Короткие службы](https://docs.zepp.com/docs/guides/framework/device/app-service/)

Для проверки на часах запустите трёхминутный раунд в смешанном режиме, дождитесь естественного выключения экрана и проверьте короткий сигнал через 30 секунд, двойной через минуту и длинный на финише.

## Установка на часы

1. Подключите Bip 6 к телефону в Zepp. Если режим разработчика ещё выключен, в Zepp откройте «Профиль» → «Настройки» → «О приложении» и семь раз нажмите на логотип Zepp.
2. В Терминале из папки проекта запустите команды ниже. Если Zeus откроет форму входа, войдите в аккаунт Zepp.
3. На телефоне в карточке Bip 6 откройте «Режим разработчика» → `+` → `Scan` и отсканируйте QR-код из Терминала. Телефон и Mac должны находиться в одной сети Wi-Fi. Оставьте команду запущенной до конца установки. Откройте «Таймер стойки» (Saiga Stance Timer) из списка приложений часов. [Руководство Zepp](https://docs.zepp.com/docs/guides/quick-start/preview/)

```sh
npm ci
npm run preview -- --local
```

## Сборка

```sh
npm ci
npm test
npm run build
```

Пакет `.zab` появится в `dist/`. Для запуска в Zepp Simulator с профилем Bip 6 используйте `npm run dev`.

## Готовый пакет

Собранного пакета в архиве нет: `npm run build` создаёт `dist/*.zab`, и его можно приложить к релизу на GitHub. Для установки на свои часы используйте QR из раздела «Установка на часы».
